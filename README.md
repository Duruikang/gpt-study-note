## 📖 项目简介

本仓库整理了我在学习过程中，通过 ChatGPT 辅助生成的 **算法图解、数据结构说明和计算机基础知识笔记**。

特点：

* 🧠 图解为主，降低理解难度
* 🪜 从基础到进阶，适合系统复习
* 💡 强调思路，而不是死记代码
* 🎯 面向技术面试高频知识点
* 🤖 利用 GPT 提升学习效率

适合人群：

* 准备算法面试的开发者
* 想系统复习数据结构的工程师
* 转岗 IT / 软件工程岗位的人
* 希望通过图解理解复杂概念的学习者

## 🧭 学习路线建议

推荐按以下顺序学习：

### 1️⃣ 数据结构基础

* 数组
* 链表
* 栈
* 队列
* 哈希表（HashMap 原理）
* 二叉树基础

### 2️⃣ 树结构进阶

* 二叉搜索树（BST）
* 平衡二叉树（AVL）
* 红黑树

### 3️⃣ 搜索算法

* 深度优先搜索 DFS
* 广度优先搜索 BFS
* 二分查找

### 4️⃣ 图算法

* 有向图
* 无向图
* 加权图
* 最短路径算法
* Dijkstra

### 5️⃣ 动态规划

* 状态定义
* 状态转移方程
* 滚动数组优化
* 常见 DP 模型

### 6️⃣ 常见排序算法

* 冒泡排序
* 选择排序
* 插入排序
* 快速排序
* 归并排序
